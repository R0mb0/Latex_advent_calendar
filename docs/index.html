Printable Advent Calendar for Classrooms & Makers

Generate crisp, cut-ready Christmas baubles and gift boxes directly from LaTeX. Fill the 24 days with math problems, riddles, challenges, or quotes—ready for color or coloring-book printing.

📄 Preview Sample PDF ⭐ View on GitHub

Designed to Print, Cut & Enjoy

Every detail is configurable right at the top of a single .tex file.

🎁

Baubles & Gift Boxes

Toggle Christmas baubles, gift boxes, or both at once. One centralized list of 24 texts updates every shape automatically.

🎨

Color or Coloring-Page

Switch between a festive full-color version and a clean black-and-white outline mode that kids can color by hand.

🔄

4 Duplex Back Modes

Choose front-only, identical back, decorative graphic back, or custom back text (perfect for printing answers or solutions).

✂️

Auto-Aligned & Cut-Ready

Mirrored columns for double-sided (long-edge) printing with optional dashed cut guides and zero blank pages on A4 paper.

⚙️

Works Everywhere

Fully compatible with pdfLaTeX, XeLaTeX, LuaLaTeX, Overleaf, or automated compilation via GitHub Actions.

🏫

Built for Any Theme

Great for daily math problems, language riddles, kindness challenges, or inspirational holiday quotes.

Create Yours in 3 Steps

No local LaTeX installation required if you use GitHub Actions.

1

Fork the Repository

Fork the project on GitHub and enable the Actions tab on your copy.

2

Customize Parameters

Edit advent_calendar.tex to pick shapes, colors, back mode, and your 24 daily texts.

3

Download & Print

Commit your changes, download the compiled PDF from the latest Action run, print duplex, and cut!
